Reproducibility and replication

Reproducibility

Same data, same analysis.

Replication

New data, same question.

Forty-five seconds. Use the National Academies' 2019 definitions. Reproducibility means obtaining consistent computational results with the original data, code, methods and analysis conditions. Replication asks whether a finding is consistent in a study collecting its own data to answer the same question. Different populations or interventions instead bear on generalizability. Transparency makes the material available for inspection; it does not itself establish successful reproduction or replication.
