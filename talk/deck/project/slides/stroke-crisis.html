Stroke research needs inspectable evidence

Protocols explain what was planned.

Data and code enable independent checks.

Different patients can produce different results.

Fifty seconds. Now move from replication evidence in other disciplines to transparency in stroke. Animal-to-human translation is a generalizability problem. Trials enrolling different patients or using different interventions do not automatically test replication of the same claim. Tirofiban and subdural-haematoma trial contrasts have therefore been removed as evidence of a stroke reproducibility crisis. Access to protocols, data and code helps us investigate differences, with controlled access where patient privacy requires it. Missing public materials does not prove incorrect results.
